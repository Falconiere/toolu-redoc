# Toolu Redoc

Client-side OpenAPI 3.0/3.1 docs viewer — React + Vite console app with TanStack
Router, deployed to Cloudflare Workers. Paste or fetch a spec, browse operations,
read schemas/examples, and share stable operation links.

> **New here (human or agent)?** Read [`AGENTS.md`](./AGENTS.md) first — it's the
> repo map + conventions. This README is the orientation + run/build guide.
> **Out of scope** (Try it out, hosted platform, …) is listed below — do not invent those features.

## Quick start

```bash
bun install          # install deps (from repo root or this package)
bun run dev          # start the dev server (http://localhost:5173)
bun run build        # production build → dist/
bun run preview      # serve the build with Vite
bunx wrangler dev    # serve the build through the real Workers runtime
bun run deploy       # build + wrangler deploy
```

From the workspace root:

```bash
bun install
bun run --filter @toolu-redoc/redoc check
bun run --filter @toolu-redoc/redoc build
bun run --filter @toolu-redoc/redoc test:preview-smoke   # T27: dist + real Petstore URL load
bun run --filter @toolu-redoc/redoc preview              # interactive production preview
```

## Documented journey (T27)

1. Install and gate: `bun install` then `bun run --filter @toolu-redoc/redoc check`
   (nonempty Vitest suites must pass).
2. Production build: `bun run --filter @toolu-redoc/redoc build`.
3. Automated smoke: `bun run --filter @toolu-redoc/redoc test:preview-smoke`
   (Playwright against `dist/`: URL-load Petstore → filter → select → share → reload).
4. Interactive: `bun run --filter @toolu-redoc/redoc preview` (or `dev`), then paste
   or open `/?url=<encoded-http(s)-href>`, filter operations, select one, use
   **Copy link**. Share search params are `url` (source) and `op` (operation identity).

## Environments

| Env | When |
| --- | --- |
| development | local (`bun run dev`) |
| production | deployed Worker |

Config is read from `VITE_*` env vars and validated in `src/constants/env.ts`.
**Everything in this bundle is public** — it is a static SPA, so a secret in
`.env.local` is a secret shipped to the browser. Server-side config belongs to
the API service. Copy `.env.example` → `.env.local` and fill it in.

## Routing

Routes are files under `src/app/`, generated into `src/route-tree.gen.ts` by the
TanStack Router Vite plugin. Navigate with `<Link to="…">` so a renamed route is
a compile error, not a 404.

| Route | Role |
| --- | --- |
| `/` | Spec load (paste / URL). After success, three-column docs viewer (nav / detail / Samples). |
| `/docs` | Petstore playground wiring the docs-owned fixture into the same shell (demo only; share links target `/`). |

Share search params on `/`: `url` (absolute http(s) source href) and `op`
(`encodeOperationIdentity(method, path)`). Selecting an operation updates `op`
(history push). Document bytes are never stored in the URL or Web Storage.

## Loading an OpenAPI document

On `/` (Spec load screen):

1. **Paste** OpenAPI JSON or YAML into the text area and choose **Parse paste**.
2. **URL** — enter an absolute `http://` or `https://` link (no userinfo) and
   choose **Load URL**, or open `/?url=<encoded-href>` to auto-load. Optional
   `op` selects an operation after load.
3. Loading, validation, and network failures use Signal banner/empty patterns.
   Opaque network errors offer paste recovery and **never claim a definitive CORS
   diagnosis** (the browser does not expose that).
4. HTTPS pages that load `http://` sources may be blocked as mixed content — use
   HTTPS sources or paste.
5. Limits (enforced while reading URL bytes and before parsing paste): 5 MiB
   UTF-8 input, 15 s fetch timeout, schema expansion depth 25, YAML alias bound
   100. See `src/domains/openapi/api/openapi-limits.ts`.
6. Latest load wins; Reset clears model, selection, filter, and source identity.
   Failed replacement keeps the last successful document with a labeled error.

### Paste / link lifetime

- Paste sessions are in-memory only for that tab — there is no durable share URL
  that rehydrates pasted bytes.
- Share **Copy link** embeds `url` + `op` when the source was a URL. If the
  source URL itself carries query params, the disclosure warns that embedding
  may be lossy; paste-only loads disclose that deep links need a `url`.

### Fixture HTTP server (local tests + smoke)

Vitest load suites and `test:preview-smoke` start
`src/domains/openapi/__tests__/fixture-http-server.ts` — a real Node `http`
server on an ephemeral `127.0.0.1` port. Lifecycle: `startFixtureHttpServer()` →
use `baseUrl` → always `close()` in `finally`.

| Route | Behavior |
| --- | --- |
| `GET /fixtures/petstore.json` | Petstore OAS 3.0 JSON (`petstore-3.0.json`, SHA-256 `246cfe6eaa556e39a38fe6be1bb5c29573dbde34ddb13313b3054afc0a7e3413`) |
| `GET /fixtures/petstore.txt` | Same bytes, `text/plain` |
| `GET /fixtures/redirect` | 302 → petstore.json |
| `GET /fixtures/missing` / `error` / `login.html` / `delayed` / `oversize` | Error and boundary scenarios |

Provenance: `src/domains/openapi/__tests__/fixtures/provenance.md`. The fixture
server sends permissive CORS headers so the production bundle in Chromium can
URL-load across localhost ports during smoke (not a claim about production CORS
policy for third-party specs).

```bash
bun run --filter @toolu-redoc/redoc test            # Vitest including fixture-HTTP suites
bun run --filter @toolu-redoc/redoc test:preview-smoke
bun run --filter @toolu-redoc/redoc dev             # interactive paste / URL load
```

## Out of scope (MVP)

This viewer does **not** include:

- **Try it out** / executing requests described by the loaded spec
- Credential entry, OAuth, or authentication flows
- Hosted document platform, Turso persistence, or a backend proxy for specs
- Spec editing, linting, or Swagger 2 conversion
- Remote `$ref` fetch or automatic fetch of external example URLs
- Generated SDK / code samples
- Security-requirement display (optional epic feature; **not** accepted for MVP)

Agents must not invent these. Supported surface: OpenAPI 3.0.x / 3.1.x
presentation — parse, load, navigate, detail, Samples rail, share links.

## CI and review

- **`ci.yml`** — type-check, lint, format-check, structure check, test, **apps/redoc
  production build**, Playwright Chromium install, **preview smoke**, and
  apps/api wrangler dry-run, each as its own step, on every PR and push to `main`.
- **`code-review.yml`** — AI review of every PR against this repo's own
  convention files (read from the base branch). Needs an `OPENROUTER_API_KEY`
  repository secret.

Both should be required checks on `main`.

## Conventions

Strict TypeScript, no barrel files, no default exports, kebab-case filenames,
co-located real-data tests, thin routes, Zod at every boundary with types from
`z.infer`, oRPC + TanStack Query for our own API and `@/utilities/http` for
everything else (no axios). Full rules in [`AGENTS.md`](./AGENTS.md).
